# SEO Checklist

Use this checklist for public copy, metadata, route naming, and landing page changes.

## Current SPA Reality

- [ ] Change acknowledges QuickTools is currently a Create React App SPA.
- [ ] No route-level SEO behavior is claimed unless implemented.
- [ ] No server-side rendering or static generation is claimed.
- [ ] Metadata changes are limited to actual static app shell capabilities.

## Content Accuracy

- [ ] Product copy describes implemented tools accurately.
- [ ] Landing page does not present unimplemented tools as live routes.
- [ ] Tool names match routes in `client/src/App.tsx`.
- [ ] Future tool ideas are labeled as planned or future.

## Metadata

- [ ] Page title matches QuickTools identity.
- [ ] Description matches current product capabilities.
- [ ] Manifest fields are consistent with product name.
- [ ] Favicon and public icons remain valid.
- [ ] Robots file remains intentional.

## Structure

- [ ] Main page content has clear heading hierarchy.
- [ ] Links point to implemented routes.
- [ ] Public-facing text avoids keyword stuffing.
- [ ] Route paths are stable and descriptive.

## Documentation

- [ ] SSOT SEO section remains accurate.
- [ ] SEO strategy changes are marked as current or future.
